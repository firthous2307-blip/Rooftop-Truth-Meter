# Rooftop-Truth-Meter
AI-Assisted Rooftop Solar Performance Monitoring and Energy Loss Analysis Platform.
☀️ Rooftop Truth Meter

Smart Solar Panel Performance Monitoring and Analysis System

📌 About the Project

Rooftop Truth Meter is a web-based prototype designed to analyze rooftop solar panel performance by comparing expected and actual daily electricity generation.

It helps users identify energy-generation gaps, estimate financial losses, and understand possible reasons for reduced solar panel performance.

🎯 Problem Statement

Solar panel owners often find it difficult to determine whether their rooftop solar systems are generating the expected amount of electricity. Dust, shading, overheating, and inverter problems can reduce energy production without being noticed.

💡 Proposed Solution

Rooftop Truth Meter provides a simple dashboard where users can enter their solar system details and daily energy-generation values.

The system calculates:

- Solar panel performance efficiency.
- Difference between expected and actual energy generation.
- Estimated daily, monthly, and yearly financial losses.
- Possible reasons for reduced performance.
- Recommendations for improving solar panel efficiency.

✨ Key Features

- Performance Analysis: Compares expected and actual energy generation.
- Efficiency Meter: Displays solar system performance as a percentage.
- Energy Gap Detection: Identifies differences in electricity generation.
- Financial Loss Estimation: Calculates estimated energy-related financial losses.
- Issue-Based Recommendations: Provides suggestions based on the selected possible issue.
- Printable Report: Allows users to print their performance report.
- Responsive Dashboard: Works on desktop and mobile screens.

🛠️ Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling and responsive design.
- JavaScript – Calculations and interactive functionality.

⚙️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Open "index.html".
5. Right-click and select Open with Live Server.
6. Enter your solar panel details and click the analysis button.

📊 Sample Calculation

Example input:

- Solar capacity: 5 kW
- Expected generation: 24 kWh/day
- Actual generation: 16.8 kWh/day
- Electricity tariff: ₹8/unit

Sample output:

- Performance efficiency: 70%
- Energy generation gap: 7.2 kWh/day
- Estimated daily loss: ₹57.60
- Estimated monthly loss: ₹1,728
- Estimated yearly loss: ₹21,024

Note: These are illustrative calculations based on user-entered values, not live solar sensor measurements.
